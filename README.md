# SauceDemo Assignment

Automated end-to-end tests for the SauceDemo web application using Playwright and TypeScript.

## Project Overview

This repository contains a Playwright test automation framework for the SauceDemo site (`https://www.saucedemo.com/`). The suite covers:

- Login validation using data-driven credentials
- Inventory page verification and cart operations
- Checkout flow and order completion
- PDF order summary download and content validation

## Tech Stack

- Node.js
- TypeScript
- Playwright (`@playwright/test`)
- `pdf-parse`

## Repository Structure

- `tests/` - Playwright test specs
  - `login-test.spec.ts`
  - `inventory-test.spec.ts`
  - `checkout-test.spec.ts`
  - `autoHelper/helper.ts`
- `pom/pages/` - Page object model classes
  - `login.ts`
  - `inventorypage.ts`
  - `cart.ts`
  - `checkout.ts`
- `test-data/` - Test data JSON files
  - `creds.json`
  - `userdata.json`
- `test-results/` - Output folder for generated artifacts such as downloaded PDFs
- `playwright.config.ts` - Playwright configuration
- `package.json` - Node dependency manifest

## Setup

1. Install dependencies:

```bash
npm install
```

2. Verify Node.js is installed. Recommended version: Node 18 or newer.

## Run Tests

Execute the full suite:

```bash
npx playwright test
```

Run a single spec file:

```bash
npx playwright test tests/login-test.spec.ts
```

## Test Configuration

The test configuration in `playwright.config.ts` includes:

- `testDir: './tests'`
- HTML reporter output
- `trace: 'on-first-retry'`
- `screenshot: 'only-on-failure'`
- CI-aware retry and worker settings

## Test Data

- `test-data/creds.json` contains login credentials and user type flags.
- `test-data/userdata.json` contains checkout customer details.

## Output and Artifacts

- HTML reports are generated by Playwright after test execution.
- `test-results/order-summary.pdf` is created when the PDF order validation test runs.

## Notes

- The tests are built for `https://www.saucedemo.com/`.
- If you add new tests or data files, update the relevant page object methods and test flows accordingly.
